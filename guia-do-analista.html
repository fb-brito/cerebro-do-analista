Operações Matemáticas & Fórmulas Percentuais

Variação MoM/YoY blindada contra erros, participação relativa e PROCX mestre.

Simulador de Variação %

MoM / YoY

Teste variações reais e confira a fórmula blindada para não exibir #DIV/0! ou sinais invertidos com bases negativas.

R$
R$
Variação Calculada:
+25,00% +R$ 250,00

Crescimento de R$ 250,00 sobre a base anterior.

Fórmula Blindada Excel: 
=SE(B2=0; "-"; (C2-B2)/ABS(B2))
Versão EN-US: 
=IF(B2=0, "-", (C2-B2)/ABS(B2))

O uso de ABS() no denominador evita inverter o sinal matemático quando a base inicial for negativa (ex: prejuízo que reduz).

% do Total (Share)

Representatividade de uma linha sobre o total geral fixado.

=B2 / $B$10
Trave com $B$10 para arrastar a fórmula.

Margem Bruta (%)

O quanto sobra de cada R$ 1 faturado após os custos diretos.

=(B2 - C2) / B2
Onde B2=Receita e C2=Custo.

Acréscimo / Desconto

Aplica fator multiplicador direto em uma única operação.

=B2 * (1 + 0,15)
+15% de reajuste sem precisar somar em 2 etapas.

Atingimento de Meta

Mede o cumprimento do orçamento/forecast (% Target).

=Realizado / Meta
> 100% = meta superada; < 100% = gap operacional.

Agregações Condicionais com Comparador Dinâmico

O truque de ouro para filtrar por intervalos de datas e critérios dinâmicos usando o operador &: 

=SOMASES(C:C; A:A; "Prosegur"; B:B; ">=" & F1; B:B; "<=" & F2)
Onde F1 é Data Inicial e F2 é Data Final.
Evolução do PROCV

Laboratório PROCX (XLOOKUP) Mestre

Esqueça as limitações do PROCV: busca para a esquerda, tratamento nativo de erro, caracteres curinga e busca de baixo para cima.

=PROCX(pesquisa; mat_pesq; mat_retorno; [se_não_encontrado]; [modo_corresp]; [modo_pesq])
Técnica 1

Busca com Curingas (* e ?)

Encontra o valor mesmo digitando apenas parte do nome ou código do cliente.

=PROCX("*" & A2 & "*"; A:A; B:B; "-"; 2)
O argumento 2 ativa modo curinga.
Técnica 2

Última Ocorrência (Reversa)

Pega o status mais recente em tabelas ordenadas por data (de baixo para cima).

=PROCX(A2; A:A; D:D; "-"; 0; -1)
O argumento -1 pesquisa do fim ao início.
Técnica 3

Matriz Bidirecional (2D)

Cruza Linha x Coluna (ex: Região x Tarifa de Serviço) sem ÍNDICE/CORRESP.

=PROCX(Linha; A:A; PROCX(Col; 1:1; A:Z))
PROCX aninhado no argumento de retorno.
Técnica 4

Multicritério (E Lógico)

Busca por 2 ou mais colunas simultaneamente sem precisar concatenar dados.

=PROCX(1; (A:A=X)*(B:B=Y); C:C)
Multiplicação booleana (1*1=1).

O Laboratório de Rankings

As 3 formas definitivas de ranquear no mercado: Tabela Dinâmica, Power Query e DAX (RANKX).

Método 1: Nativo Excel Zero Fórmulas

Ranking via Tabela Dinâmica

O método mais rápido e elegante para criar rankings e listas Top N no Excel sem alterar uma única linha da sua base bruta.

Cliente / Parceiro Faturamento Classificação Posição
1 Rede Varejo Alfa R$ 185.000 1º do Maior Top 1
2 Banco Central Sul R$ 142.000 2º do Maior Top 2
3 Shopping Metrópole R$ 98.500 3º do Maior Top 3

Roteiro de Configuração (4 Cliques):

  1. Arraste o campo numérico (ex: Faturamento) para a área de Valores duas vezes.
  2. Na segunda coluna criada, clique com o botão direito sobre qualquer número ➔ Mostrar Valores Como.
  3. Escolha a opção: "Classificação do Maior para o Menor..." e selecione o campo de Linha (ex: Cliente).
  4. Para limitar no Top 10: Clique no filtro de cabeçalho de Linha ➔ Filtros de Valores ➔ Os 10 Primeiros...
Vantagem Executiva: Ao atualizar a base de dados (Alt + F5), o ranking e a ordem do Top N são recalculados automaticamente sem risco de fórmulas quebradas!
Método 2: ETL no Power Query

Ranking Persistido no ETL

Quando você precisa que o ranking já venha gravado como coluna física na tabela antes de gerar gráficos ou relatórios. 

// Passo 1: Ordenar pela métrica em ordem decrescente
#"Linhas Ordenadas" = Table.Sort(#"Tipo Alterado", {{"Faturamento", Order.Descending}}),

// Passo 2: Adicionar coluna de índice começando do 1
#"Ranking Adicionado" = Table.AddIndexColumn(#"Linhas Ordenadas", "Ranking_Geral", 1, 1, Int64.Type)

Como Fazer pelos Menus:

  1. Clique na seta da coluna numérica e selecione Classificar em Ordem Decrescente.
  2. Vá na guia Adicionar Coluna ➔ clique em Coluna de Índice ➔ selecione De 1.
  3. Dê um duplo clique no cabeçalho da nova coluna e renomeie para Ranking.
Ranking por Categoria (Ex: por Filial ou Região): Use a ferramenta Agrupar Por com a operação "Todas as Linhas", adicione o índice na subtabela via Table.AddIndexColumn e expanda.
Método 3: Power BI (DAX Avançado)

A Medida Canônica de Ranking: RANKX Profissional

A estrutura blindada que evita os dois erros clássicos: rankear o "Total Geral" e pular posições em empates. 

Rank_Cliente = 
IF(
    // 1. Só calcula se estiver no nível de linha (remove ranking do Total)
    ISINSCOPE(dCliente[Nome_Cliente]),
    
    // 2. Calcula o ranking dinâmico respeitando filtros do dashboard
    RANKX(
        ALLSELECTED(dCliente[Nome_Cliente]),
        [Total_Faturamento],
        ,
        DESC,
        Dense // 3. Não pula posições em caso de empate (1, 2, 2, 3...)
    )
)

Anatomia do DAX Profissional:

1. ISINSCOPE(Coluna)

Garante que a medida só retorne número nas linhas dos clientes. Na linha de Total Geral, retorna em branco em vez do constrangedor "1º Lugar".

2. ALLSELECTED(Coluna)

Faz o ranking recalcular respeitando os filtros de período e região da tela, mantendo a escala de 1 a N no segmento selecionado.

3. Parâmetro "Dense"

Se houver dois clientes empatados em 2º lugar, o próximo será o 3º (e não o 4º como no modo padrão *Skip*).

O Quarteto Fantástico do Analista em DAX (Cheat Sheet)

CALCULATE(Medida; Filtro)

O motor do DAX. Altera o contexto de avaliação aplicando novos filtros ou modificando existentes.

ALL(Tabela ou Coluna)

Remove todos os filtros da tabela ou coluna. Essencial para calcular percentuais sobre o total geral.

DIVIDE(Num; Denom; [Alt])

Divisão segura com tratamento de divisão por zero nativo. Retorna nulo ou valor alternativo.

USERELATIONSHIP(Fk; Pk)

Ativa relacionamentos secundários inativos (ex: cruzar com calendário por Data de Fechamento).

Padrão Diretoria 1 Excel: Gráfico de Combinação

Barras com Linha de Meta Tracejada

Mostra o realizado por cliente/filial com uma linha de meta limpa, sem poluição de eixos secundários desalinhados.

Realizado vs. Meta (k R$) Realizado Meta (100k)

Como Parametrizar no Excel:

  1. Tabela base: coluna A (Filial/Cliente), coluna B (Realizado), coluna C (Meta repetida para todas as linhas).
  2. Selecione as 3 colunas ➔ Menu Inserir ➔ Gráficos ➔ Gráfico de Combinação (Coluna Agrupada e Linha).
  3. O Pulo do Gato: Desmarque a caixa "Eixo Secundário" na série de Meta para que barras e linha usem a mesmíssima escala vertical.
  4. Clique na linha de meta ➔ Ctrl + 1 ➔ Em Linha, marque Linha Sólida, escolha cor contrastante e em Tipo de Traço selecione Tracejado.
  5. Em Marcador, deixe selecionado Nenhum.
Resultado: A linha tracejada estabelece a fronteira visual instantânea. Quem cruza a linha bateu a meta; quem fica abaixo fica imediatamente evidente sem exigir esforço cognitivo da audiência.
Padrão Diretoria 2 Tendência Temporal Limpa

Linha Suave com Marcadores Extremos

Elimina as bolinhas poluídas em todos os meses, destacando apenas o pico máximo, o ponto mínimo e o fechamento atual.

Evolução de Chamados / Atendimentos (Jan-Jun) Pico em Mai (450)

O Truque Matemático no Excel:

Crie duas colunas auxiliares na tabela com a função NÃO.DISP():

Pico: =SE(B2=MÁXIMO($B$2:$B$13); B2; NÃO.DISP())
Mín:  =SE(B2=MÍNIMO($B$2:$B$13); B2; NÃO.DISP())

O Excel não plota células com o erro #N/D. Assim, as séries de pico e mínimo só geram marcadores onde forem os valores recordistas!

Visual Limpo: O gráfico de linha suavizada conduz o olhar sem ruído, e os dois pontos estratégicos atraem a atenção imediata na apresentação.
Padrão Diretoria 3

Gráfico de Pareto Executivo (Princípio 80/20)

Identifique com clareza matemática os 20% das causas que respondem por 80% dos custos, glosas ou chamados.

Barras Descendentes + Linha Acumulada
Análise de Ocorrências / Custos Operacionais % Acumulado (80%)

Construção Nativa no Excel:

  1. Ordene os motivos/custos em ordem estritamente decrescente.
  2. Crie a coluna de % Acumulado somando as participações anteriores: =SOMA($B$2:B2)/$B$7.
  3. No Excel moderno (2016+): Selecione os dados ➔ Guia Inserir ➔ Gráficos ➔ Gráfico de Estatística ➔ clique direto no ícone Pareto!
  4. O Excel criará as colunas já ordenadas e a linha acumulada no eixo secundário automaticamente.
Conclusão Executiva: Resolvendo apenas os dois primeiros itens ("Alarme Falso" e "Falha de Sensor"), 70% dos problemas operacionais são eliminados!

Checklist de "Decluttering": O que Deletar Antes de Apresentar

❌ 1. Linhas de Grade Pesadas

Clique nas linhas horizontais do fundo e aperte Delete. Rótulos já informam o valor.

❌ 2. Borda e Fundo do Gráfico

Coloque "Sem Linha" e "Sem Preenchimento" na área do gráfico para ele flutuar perfeitamente na lâmina.

❌ 3. Legendas Desnecessárias

Se o gráfico só tem uma série de barras, delete a legenda "Faturamento". O título já explica o dado.

✅ 4. Título com Insight

Em vez de "Gráfico de Vendas", use: "Sul e Leste superaram a meta de 100k impulsionados pelo Varejo".

Automação Rápida de Rotinas

Receitas de 1 clique para consolidar pastas e desdinamizar no Power Query, mais macros essenciais de VBA.

ETL de Pasta (M)

Empilhar Múltiplos Arquivos de uma Pasta

Pare de copiar e colar 20 arquivos mensais de prestadores. Configure a importação da pasta e junte tudo em segundos. 

// 1. Conectar na pasta local ou de rede
Fonte = Folder.Files("C:\Operacoes\Medicoes\"),

// 2. Filtrar apenas planilhas Excel e ignorar arquivos temporários do Windows
#"Arquivos Filtrados" = Table.SelectRows(Fonte, each 
    [Extension] = ".xlsx" and not Text.StartsWith([Name], "~$")
),

// 3. Extrair e combinar as tabelas internas
#"Tabelas Combinadas" = Table.TransformColumns(#"Arquivos Filtrados", 
    {"Content", each Excel.Workbook(_){[Item="Planilha1",Kind="Sheet"]}[Data]}
)

Como Fazer pelos Menus:

  1. Guia Dados ➔ Obter Dados ➔ Do Arquivo ➔ Da Pasta.
  2. Selecione a pasta onde caem os relatórios mensais e clique em Transformar Dados.
  3. Filtro de Segurança: Na coluna Name, filtre para excluir nomes que começam com ~$ (evita erro de arquivo aberto no Excel).
  4. Clique no botão com duas setinhas para baixo no cabeçalho da coluna Content (Combinar Arquivos).
No mês seguinte, basta jogar o novo arquivo na pasta e apertar Alt + F5 para a base consolidar sozinha!

Transforme relatórios matriciais (meses na horizontal) em tabelas verticais para alimentar gráficos e tabelas dinâmicas.

A base verticalizada permite filtrar por mês como segmentação de dados e calcular métricas DAX sem dor de cabeça.
VBA Express

Macro de Limpeza & Formatação Executiva em 1 Clique

Transforme relatórios brutos e feios exportados de sistemas legados em tabelas executivas formatadas e limpas instantaneamente. 

Sub FormatarRelatorioExecutivo()
    Dim ws As Worksheet
    Dim ultimaLinha As Long
    Dim ultimaColuna As Long
    
    ' 1. Otimização de Performance: Desativa tela para rodar instantaneamente
    Application.ScreenUpdating = False
    Application.DisplayAlerts = False
    
    Set ws = ActiveSheet
    
    ' 2. Descobre a última linha e coluna preenchidas
    ultimaLinha = ws.Cells(ws.Rows.Count, 1).End(xlUp).Row
    ultimaColuna = ws.Cells(1, ws.Columns.Count).End(xlToLeft).Column
    
    If ultimaLinha < 2 Then Exit Sub
    
    With ws
        ' 3. Formata o Cabeçalho (Azul Marinho Corporativo + Texto Branco em Negrito)
        With .Range(.Cells(1, 1), .Cells(1, ultimaColuna))
            .Interior.Color = RGB(15, 23, 42) ' Slate-900 elegante
            .Font.Color = RGB(255, 255, 255)
            .Font.Bold = True
            .Font.Name = "Segoe UI"
            .Font.Size = 10
            .HorizontalAlignment = xlCenter
        End With
        
        ' 4. Formata o Corpo de Dados (Fonte Limpa + Bordas Leves)
        With .Range(.Cells(2, 1), .Cells(ultimaLinha, ultimaColuna))
            .Font.Name = "Segoe UI"
            .Font.Size = 9
            .Borders.LineStyle = xlContinuous
            .Borders.Color = RGB(226, 232, 240)
            .Borders.Weight = xlHairline
        End With
        
        ' 5. Autoajuste de Largura de Colunas
        .Columns.AutoFit
    End With
    
    ' 6. Restaura configurações do Excel
    Application.ScreenUpdating = True
    Application.DisplayAlerts = True
    
    MsgBox "Relatório formatado com sucesso!", vbInformation, "Cérebro do Analista"
End Sub
